# Floppyy

**The web you grew up on.**

Floppyy is a browser desktop built on pure nostalgia.

Boot up, click around, remember everything — minus the dial-up wait.

Mostly.

---

## What is Floppyy?

Floppyy is a tiny retro computer in your browser.

It brings back the feeling of old desktop systems, pixel windows, floppy disks, BIOS boot screens, Winamp vibes, classic games, and the early web — rebuilt as a playful browser experience.

---

## Features

- BIOS-style boot sequence
- Windows 98-inspired desktop
- Pixel windows and taskbar
- Internet Explorer / Netscape-style browsing
- Old web pages powered by the Internet Archive
- Winamp-inspired music player
- Retro games
- Shutdown / restart flow
- Mobile-friendly browser desktop
