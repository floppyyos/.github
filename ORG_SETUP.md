Use this in the GitHub org description field:

```txt
Floppyy — the web you grew up on. A nostalgic browser desktop built on pure retro computer vibes.
```

## Profile repository structure

Create this repository inside the organization:

```txt
.github
```

Then add this file:

```txt
profile/README.md
```

GitHub will render it automatically on the organization profile page.

## Banner

Recommended path:

```txt
.github/profile/assets/floppyy-banner.png
```

Then uncomment/add this block at the top of `profile/README.md`:

```md
<p align="center">
  <img src="./assets/floppyy.jpg" alt="Floppyy — The web you grew up on." width="100%" />
</p>
```
